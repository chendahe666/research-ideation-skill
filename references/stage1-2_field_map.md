## 提示词（给执行 skill 的模型用，也可以贴到别的 AI 里）

### P1 · 建领域本体
```
你是 <领域> 的资深研究者，现在要给刚进组的博士生写一份入门手册。
只依据我提供的论文列表/摘要（以及你能检索到并核实的资料）作答，不要凭记忆补引用。
请按以下结构输出：问题定义、对象与表示、威胁模型/实验设定、评测体系、主流 baseline、
核心团队与 venue、术语表。每条事实后标出处（标题, 年份, venue）；无法核实的标 [未核实]。
```

### P2 · 画演化地图
```
基于入门手册和按年份整理的论文列表，画出这个领域过去 10 年的演化地图。要求：
1. 分 3–5 个时期。每期写清主导范式、代表作、解决了什么、默认了什么假设、怎么评测、留下了什么问题。
2. 指出推动范式转换的驱动力（技术 / 数据 / 需求 / 制度）。
3. 构建至少 2 条"演化链"：每一环都说明它修补了上一环的什么缺陷，并外推下一环。
4. 列出至今仍有争议或结论互相矛盾的问题，并分析可能原因（设定 / 指标 / 数据不同）。
5. 用"对象 × 目标/场景"组合矩阵找出空白格，并判断每个空白是真的没人做，还是组合本身没有意义。
写的是"变化"，不是论文清单。示例写法："早期主要关注 X 的准确率 → 后来关注可解释性 → 现在更多关注可信度和实际落地。"
```

### P3 · 自检
```
检查这份地图：
(a) 有没有哪个时期只写了方法、没写默认假设？
(b) 演化链的每个箭头都有论文支撑吗？
(c) 最近 12 个月的重要工作漏了吗？请列出应该补查的关键词。
(d) 地图有没有偏向我给的种子论文所在的流派？还有哪些平行流派？
```

## 查询拆分技巧

- 大话题拆成"对象 × 任务"：`"3D Gaussian splatting" watermark`、`NeRF watermark`、`"point cloud" watermarking`、`"3D mesh" watermarking`、`"text-to-3D" watermark`、`"image-to-3D" copyright`
- 同一个概念要检索它的各种同义词：watermark / steganography / fingerprint / copyright protection / provenance
- 跨领域检索时，把相邻领域的关键词换进来，例如 `LLM watermark`、`diffusion watermark`，把它们的发展路径当作参照系
- 社科和教育类题目换成对应术语：`generative AI` + `self-regulated learning` / `learning strategies` / `prior knowledge`；构念名称以领域内的量表名为准
